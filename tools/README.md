# Accumulated instruments

This directory is the repository's miscellaneous tracked toolbox.

Put tools, programs, or scripts here when they are useful/important enough to preserve with Machine-Soul but are **not intrinsically part of the assimilation/annexation system** and do not have a more specific home.

The Machine-Soul deployment runtime, application declarations/wrappers, and broad manager belong under `annexation/`, not here.

Do not invent contents merely to justify this directory's existence.


## Preserved tools

- [scrcpy_virtual_screen_manager/](scrcpy_virtual_screen_manager/) — interactive
  multi-virtual-display scrcpy manager, Windows organizer/grouping experiments,
  and optional patched-server per-app audio isolation.
