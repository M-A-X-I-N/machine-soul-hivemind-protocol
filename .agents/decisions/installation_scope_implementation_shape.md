# Installation scope implementation shape

The INST-A investigations produced a six-task implementation block:

- mutation-side scope policy;
- scoped multi-record provenance;
- candidate-exact ownership lifecycle;
- WinGet explicit scope;
- Apt fixed machine scope;
- final integration and initiative/update handoff.

Future Flatpak/Homebrew/pipx/etc. support remains in the OPEN `MSHP-INST-SCOPE` initiative without executable tasks. This is intentional and is the first production use of the reminder → initiative → task separation.

`MSHP-APPS-A-010` remains dependency-independent but is scheduled after the scope implementation because it investigates WinGet settings that must not influence Machine-Soul-controlled scope.
