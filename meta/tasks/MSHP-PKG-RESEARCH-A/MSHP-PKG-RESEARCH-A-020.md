# MSHP-PKG-RESEARCH-A-020 — Research Homebrew and Linuxbrew ownership semantics

## Description

Investigate Homebrew/Linuxbrew prefixes, accounts, formulae/casks, sources, versioning, services, upgrades and package install ownership.

## Requirements

- Document platform applicability, machine-vs-user scope, brew-prefix provenance, rollback and clash with apt/pacman; compare use on macOS versus Linux without making macOS an active target.

## Constraints / non-goals

- Research only; no blanket support promise.

## Acceptance criteria

- Integration feasibility and scope model documented.

## Validation

- Inspect current source/architecture and authoritative references relevant to the task.
- Record reproducible findings or targeted validation evidence; explicitly flag untestable claims.
