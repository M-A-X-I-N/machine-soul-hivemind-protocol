# MSHP-PLATFORM-A-020 — Plan lower-priority Manjaro/Arch-family support

## Description

Synthesize Arch/Manjaro backend research into a lower-priority distro integration plan across environment detection, pacman, configuration and fresh-machine validation.

## Requirements

- Document Manjaro-specific differences, upgrade policies, trust, AUR boundaries and CI feasibility; clearly separate read-only discovery from mutating installation.

## Constraints / non-goals

- Do not implement or prioritize over Windows/Debian until platform research supports it.

## Acceptance criteria

- Future Arch-family work is explicitly bounded with dependencies on pacman research.

## Validation

- Inspect relevant source, documentation and supported-platform evidence.
- Preserve findings, counterexamples and proposed validation commands in the task workspace.
