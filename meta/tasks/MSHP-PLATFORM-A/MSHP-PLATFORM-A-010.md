# MSHP-PLATFORM-A-010 — Audit Windows 11 and Debian/Ubuntu Server support gaps

## Description

Identify the practical gap between current Windows and Debian-family annexation support and the desired high-priority fresh-machine support targets.

## Requirements

- Inventory required application methods, OS versions, architecture, admin/account behaviors, headless server constraints, provisioning/bootstrap and CI testing; prioritize actual gaps rather than rediscovering completed features.

## Constraints / non-goals

- Research only; don't equate a passing wrapper test with full platform coverage.

## Acceptance criteria

- A prioritized and evidence-based Windows 11 plus Debian/Ubuntu Server support roadmap is documented.

## Validation

- Inspect relevant source, documentation and supported-platform evidence.
- Preserve findings, counterexamples and proposed validation commands in the task workspace.
