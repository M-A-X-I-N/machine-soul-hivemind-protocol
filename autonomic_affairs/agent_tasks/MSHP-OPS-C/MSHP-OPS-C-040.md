# MSHP-OPS-C-040 — Codify top-level directory contract

## Description

Make repository placement rules unambiguous while preserving the deliberately opaque meme names.

## Requirements

- Add a binding top-level directory contract to root agent instructions, including both belongs-here and does-not-belong-here guidance.
- Cover `abandoned_artifacts`, `accumulated_instruments`, `acquired_intelligence`, `annexation_procedures`, `arcane_experiments`, `assembled_assets`, `assimilation_directives`, `autonomic_affairs`, `.agents`, `.github`, and ignored `scratch/`.
- Use the preserved experimental/v1 doctrine plus current repository behavior; retain the meme naming.
- Ensure `assembled_assets` is treated as inert/static reusable resources and `autonomic_affairs` as repository self-management/control-plane material.

## Constraints / non-goals

- Do not rename the meme directories.
- Do not move existing content merely to demonstrate the taxonomy unless it is clearly misclassified and safe.
- Do not bury the binding rules only in optional human documentation.

## Acceptance criteria

- An agent reading required startup instructions can classify new material correctly.
- All principal top-level domains have explicit positive and negative placement guidance.

## Validation

- Cross-check current root contents and historical v1 doctrine.
- Review representative ambiguous examples.
